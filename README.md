# Western Payroll

Updated version:
- Excel export opens with an Individual Payroll sheet first.
- Each row is one employee/check, not one lump total.
- Includes current pay and YTD totals for each employee.
- Adds separate individual sheets for each employee in the payroll run.
- Adds the employee list from the screenshots automatically if missing.
- Employees remain editable in the Employees tab.

Run on Mac:

```bash
cd ~/Downloads
unzip western_payroll_individual_employee_export_seeded.zip
cd western_payroll_individual_employee_export_seeded
./run_mac.sh
```
